# RD.md — 原始需求文档（Requirements Definition）

> 本文档为项目启动时的原始需求录入，作为后续 UI/API 设计与开发的基准。
> 录入时间：2026-10-11

## 1. 项目目标

在工作目录 `E:\my_projects\qwen3_tts` 下，构建一个**基于 qwen3_tts 的配音管理网站**。

## 2. 已有基础

- **TTS 引擎**：qwen3_tts 已通过基本测试，参考 `utils/qwen3_tts_util.py`，包含三类能力：
  - 预设音色（speaker）合成
  - 音色设计（voice design，通过 instruct 描述生成新音色）
  - 音色克隆（voice clone，基于参考音频 + 参考文本）
- **Python 环境**：已安装于 `.venv`（Python 3.12.9，CUDA 可用，RTX 3080）。
- **Web 目录**：`web/` 为基础前端目录结构，技术栈 **Vue3 + TypeScript + NaiveUI**，已含 vue-router、vue-i18n、axios。
- **存储**：如需数据库，使用 `utils/moofile_util.py`（MooFile BSON 文件库），结果统一存放 `data/` 目录；必要配置放入 `.env`。

## 3. 核心功能

| 模块 | 说明 |
|------|------|
| 音色管理 | 维护音色库（预设 / 克隆 / 设计产生的音色），支持列表、试听、删除等 |
| 音色克隆 | 上传参考音频 + 参考文本，生成可复用音色 |
| 音色设计 | 通过文字描述（instruct）设计新音色 |
| 文本转语音 | 提交文本生成语音，采用**异步 task 列表**方式 |
| 语音下载 | 合成结果可下载（wav 等格式） |
| 合成履历管理 | 记录每次转换使用的音色、文本、创建/完成时间、耗时等，可查看与追溯 |

## 4. 语言与流式方针

- 主要支持 **中文、日语、英语** 三种语言。
- 模式支持**混合自动检测模式（auto）**。
- 参考 `E:\my_projects\deepagents_acp\api\chat_voice\edge_tts.py` 的流式设计：
  **基本方针：将长句拆分 → 逐段转语音 → 合并输出。**

## 5. 技术与交付要求

1. **详细设计**：基于以上信息做详细的 UI 和 API 设计，保留 Markdown 文档至 `docs/` 目录。
   - UI 需结合 **NaiveUI 组件库**：圆角化、多图标、具体到整体配色、布局、自适应、loading 等效果。
   - 多语言支持：中、日、英。
   - API 使用 **FastAPI**，符合 **RESTful** 风格，**默认端口 9001**。
2. **开发**：
   - API 放置到 `api/` 目录作为子路由。

5. **收尾**：关闭所有服务，提交代码至 GitHub。
